# Keyword Opportunity Research Skill

这是一个可上传的 ChatGPT / Agent Skills 工作流包，用于：

- 关键词研究
- 网站功能/页面需求地图
- SERP 证据记录
- 垂直长尾需求挖掘
- 小而美 SaaS 机会发现
- 全部研究过程实时输出在当前会话

## 文件

- `SKILL.md`：主工作流
- `references/EVIDENCE_MODEL.md`：E0–E6
- `references/CONTROLLED_VOCABULARY.md`：受控状态/关系词
- `references/OUTPUT_TEMPLATES.md`：会话输出模板
- `references/EXAMPLES.md`：正确/错误示例

## 安装

如果你的 ChatGPT 账号有 Skills：

1. Sidebar → Plugins
2. Skills
3. Create
4. Upload from your computer
5. 上传本 ZIP，或上传解压后的 Skill 文件夹
6. 审核内容后安装

也可以在 Skills → Create → Create with chat 中让 ChatGPT 基于这些文件创建。

## 使用

安装后可直接说：

- `使用 keyword-opportunity-research 研究 image upscaler`
- `研究 https://example.com/，全过程输出在会话`
- `研究 speech correction，重点找垂直领域长尾与小而美 SaaS 机会`

如果没有 ChatGPT Skills 权限，可以把 `SKILL.md` 放进 Project Instructions / 项目文件中作为工作流规范使用。
